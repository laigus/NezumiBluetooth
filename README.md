# 耗耗蓝牙微信小程序

一个完全本地、可扩展的 BLE 设备适配与控制小程序。项目负责发现设备、建立连接、查看 GATT、发送与接收数据，并在识别到具体设备后加载对应的协议控制器和功能页面。

项目不把某一种设备的协议或界面写进 BLE 核心。不同设备可以使用不同的广播识别方式、服务与特征、通信协议、数据模型和控制页面；例如时序控制设备可以展示计划列表，灯控设备可以展示开关、亮度和颜色。

## 项目分层

### BLE 核心

- 扫描附近设备；
- 建立和断开 BLE 连接；
- 发现服务与特征；
- 订阅通知、读取数据、分包写入；
- 管理当前连接会话与基础日志。

这部分不导入任何具体设备模块。

### 设备模块

每种正式支持的设备位于 `miniprogram/devices/<device>/`，自行声明：

- 如何从广播中识别设备；
- GATT 与传输配置；
- 协议命令和通知解析；
- 控制页面入口；
- 该设备独有的功能和数据。

设备模块之间不要求具有相同功能。新增设备只注册自己的模块，不修改其他设备的实现。

### 本地工具

本地辅助工具位于 `tools/<device>/`。工具同样按设备隔离，仅在对应设备确实需要时创建，不设统一入口，也不假定所有设备都需要抓包、频率或相同的导入格式。

## 小程序入口

- **设备管理**：识别已注册的设备模块，连接后按模块声明打开对应功能页。
- **高级调试**：由用户手动开始扫描，可查看任意 BLE 设备的服务、特征和能力，并进行 HEX/文本收发与通知检查。

小程序运行和本机设备控制不依赖云函数或业务服务器。

## 开发入口

- 第一次接触微信小程序：阅读 [第一次微信小程序开发指引](docs/WECHAT_MINIPROGRAM_GUIDE.md)。
- 理解模块边界或接入新设备：阅读 [架构说明](docs/ARCHITECTURE.md)。
- 使用或验证已有 COCO 模块：进入 [COCO 文档](docs/coco/README.md)。

公开仓库只提供 `project.config.example.json`；本机复制为被 Git 忽略的 `project.config.json` 后，再填写自己的微信 AppID。具体步骤见开发指引。

核心校验：

```powershell
pnpm test
```

上传、预览和体验版发布仍通过微信开发者工具完成；BLE 行为使用手机真机检查。
