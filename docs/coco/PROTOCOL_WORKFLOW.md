# COCO 协议与真机验证流程

COCO 的服务、特征、写入方式、停止指令和内置频率内容以源码为准，本文只记录可重复执行的真机验证流程。

## 配置来源

| 内容 | 唯一来源 |
| --- | --- |
| 设备模块注册 | `miniprogram/devices/index.js` |
| 设备画像 | `miniprogram/devices/coco/profile.js` |
| 协议控制器 | `miniprogram/devices/coco/controller.js` |
| 手动模式编码 | `miniprogram/devices/coco/manual-protocol.js` |
| 内置频率数据 | `miniprogram/devices/coco/frequencies/` |
| 频率格式校验 | `miniprogram/utils/frequency-schema.js` |
| 调度与停止 | `miniprogram/utils/program-runner.js` |

频率通过 `deviceProfileId` 绑定设备画像。运行前会校验设备类型、帧时间、完整性摘要，以及最后一帧是否与设备画像中的停止指令一致。

## 真机确认顺序

1. 退出其他控制端，把目标设备置于可连接状态。
2. 打开“设备管理”，点击“开始扫描”，等待当前连接设备出现。
3. 点击设备进入控制页。
4. 选择任意频率，开始运行数秒后点击同一卡片的“停止”。
5. 打开循环播放，确认完成一轮后轮次增加、时间进度归零，再手动停止。
6. 点击频率卡片进入详情，重复循环与停止检查，并查看固定高度的波形预览、时长和帧数。
7. 进入“手动模式”，确认滑动条整块轨道区域都容易按中、能平滑到 0，且最低值只显示数字 `0`；从 0 开始播放，分别确认“频率”到 0 时不再动作、“吸”到 0 时不再吸。
8. 在持续播放中把频率一次从高位拖到低位后直接松手，确认设备立即跟随最终低值，不需要第二次调整。
9. 点击“创建频率”，做一段短操作后停止、命名并保存；回到列表完整运行一次新条目。
10. 点击该本机条目进入详情，检查页面底部与导出按钮同级的“修改名称”和“删除频率”按钮；列表和频率信息区都不显示管理操作。
11. 对照原控制动作确认变化趋势、总时长与结束状态。
12. 需要查看底层数据时进入“高级调试”，手动开始扫描并复制会话记录。

## 通过条件

- 设备管理只连接符合当前设备画像的目标，并展示当前连接设备。
- 连接后选择设备画像配置的写入与通知通道。
- 完整运行按原顺序发送全部频率帧，最后一帧是设备画像配置的停止指令。
- 提前停止会清除剩余调度，并额外发送停止指令。
- 重复完整运行时，动作趋势与总时长保持一致。
- 页面转入后台或主动断开后，设备处于停止状态。
- 导入文件后，新频率直接出现在当前设备的频率列表中。
- 详情页导出的频率能够再次通过完整性校验。
- 列表和详情的进度都按已运行时间与总时长计算。
- 列表和详情都能选择循环；每轮不跳帧，停止后不再开始下一轮。
- 手动模式运行中连续滑动按节流间隔发送最新参数组合，不并发写入积压的旧值；松手后的最终值会强制重发。
- “频率”或“吸”单独调到 0 时，会先全局停止并恢复仍大于 0 的另一项；两项均为 0 时设备保持停止。从高频一次拖到低频后无需再次调整。
- 手动录制条目包含成功发送的双通道帧和最终停止帧，保存后可直接运行、导出和再次导入。
- 本机条目的改名和删除只在详情页底部显示，按钮有完整触控尺寸但不占主操作区；列表与频率信息区不显示管理入口。内置条目保持只读，删除确认后重新进入页面也不会恢复。
- 高级调试仅在用户点击“开始扫描”后扫描，停止或切页后保持停止。

## 新频率流程

1. 按 [iPhone 蓝牙数据采集](../apple/IPHONE_BLUETOOTH_CAPTURE.md) 取得清晰、单一动作对应的诊断归档。
2. 在电脑列出候选：

   ```powershell
   python tools\coco\extract-frequency.py captures\sysdiagnose_文件.gz --list
   ```

3. 用 COCO 专属工具选中候选并生成 `.haohao-frequency.json`，检查输出的帧数、时长和 SHA-256。
4. 把文件发到微信聊天。
5. 手机进入“设备管理 → 当前连接设备”，点击“导入频率”并选择文件。
6. 先做数秒运行加停止，再完整运行。
7. 结果稳定后可继续作为本机频率使用，也可加入 `miniprogram/devices/coco/frequencies/`。

频率字段说明见 [FREQUENCY_PACKAGE.md](FREQUENCY_PACKAGE.md)。
