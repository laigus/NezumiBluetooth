# COCO 模块使用文档

本目录只记录当前 COCO 设备模块的使用、时序频率、采集和验证流程。其他设备模块可以拥有完全不同的功能与文档结构。

## 当前能力

- 从设备广播中识别并连接 COCO；
- 使用设备画像指定的 GATT 通道收发数据；
- 显示内置和手机本机导入的频率列表；
- 开始、停止并按运行时间显示进度；
- 查看频率详情与相对波形；
- 从微信文件导入频率，或导出后分享；
- 主动断开并暂停自动重连。

频率运行、导入和导出均保存在本机，不使用云函数或业务服务器。

## 连接设备

1. 退出其他可能正在连接设备的控制端。
2. 打开 COCO 设备电源。
3. 进入小程序底部的“设备管理”。
4. 等待“当前连接”中出现设备实际名称。
5. 点击设备卡片进入 COCO 控制页。

如果主动断开过连接，回到设备管理点击“扫描并连接”后才会重新寻找设备。

## 运行与停止

1. 在频率列表中找到目标条目。
2. 首次验证时点击该条目的“开始”，运行数秒后点击同一条目的“停止”。
3. 确认设备及时停止后，再次点击“开始”进行完整运行。
4. 卡片进度条按已运行时间推进，并显示已用时间与总时间。

运行期间保持小程序在前台。小程序转入后台、设备断线或主动断开时，当前计划会结束并执行停止处理。

## 查看详情与分享

1. 点击频率卡片主体进入详情页。
2. 在同一页查看运行进度、波形、时长和帧数。
3. 详情页也可以开始或停止当前频率。
4. 点击页面底部“导出 / 分享频率”生成 JSON 文件。

系统没有显示文件分享面板时，程序会把完整 JSON 复制到剪贴板。

## 导入频率

1. 把 `.haohao-frequency.json` 文件发送到微信聊天或保存到手机文件中。
2. 进入“设备管理”，点击当前连接的 COCO。
3. 点击顶部“导入频率”。
4. 选择目标 JSON 文件。
5. 导入成功后，新条目会显示“本机导入”标签。

导入时会检查设备画像、帧时间、最终停止数据和完整性摘要。导入已有文件只需要手机，不需要重新上传小程序体验版。

## 断开与重新连接

- 在 COCO 控制页点击“断开蓝牙”可立即结束当前功能并关闭连接。
- 主动断开后不会马上自动重连。
- 回到设备管理点击“扫描并连接”可恢复自动连接。

## 获取新的频率

已有频率文件可以直接在手机导入。从原控制程序的操作生成新频率，需要先在 iPhone 采集诊断数据，再在电脑运行 COCO 专属工具：

```powershell
python tools\coco\extract-frequency.py INPUT --list
```
