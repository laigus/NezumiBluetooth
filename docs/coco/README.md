# COCO 模块使用文档

本目录只记录当前 COCO 设备模块的使用、时序频率、采集和验证流程。其他设备模块可以拥有完全不同的功能与文档结构。

## 当前能力

- 从设备广播中识别并连接 COCO；
- 使用设备画像指定的 GATT 通道收发数据；
- 显示内置、手机导入和手动录制的频率列表；
- 开始、停止、循环播放并按每轮运行时间显示进度；
- 查看频率详情与相对波形；
- 从微信文件导入频率，或导出后分享；
- 对本机频率改名或删除；
- 在手动模式中实时调节“频率”和“吸”；
- 用手机直接录制手动操作、命名并保存为本机频率；
- 从控制页主动断开蓝牙连接。

频率运行、导入和导出均保存在本机，不使用云函数或业务服务器。

## 连接设备

1. 退出其他可能正在连接设备的控制端。
2. 打开 COCO 设备电源。
3. 进入小程序底部的“设备管理”。
4. 点击“开始扫描”，需要中止时点击同一位置的“停止扫描”。
5. 等待“当前连接”中出现设备实际名称。
6. 点击设备卡片进入 COCO 控制页。

设备管理不会自行扫描。主动断开或重新进入后，点击“开始扫描”才会重新寻找设备。

## 运行与停止

1. 在频率列表中找到目标条目。
2. 首次验证时点击该条目的“开始”，运行数秒后点击同一条目的“停止”。
3. 确认设备及时停止后，再次点击“开始”进行完整运行。
4. 卡片进度条按已运行时间推进，并显示已用时间与总时间。
5. 需要连续运行时先打开该条目的“循环播放”，再点击“开始”；每一轮会从零重新显示时间进度，直到手动停止。

运行期间保持小程序在前台。小程序转入后台、设备断线或主动断开时，当前计划会结束并执行停止处理。

## 查看详情与分享

1. 点击频率卡片主体进入详情页。
2. 在同一页查看运行进度、固定高度的波形预览、时长和帧数。
3. 详情页也可以开始或停止当前频率。
4. 点击页面底部“导出 / 分享频率”生成 JSON 文件。

系统没有显示文件分享面板时，程序会把完整 JSON 复制到剪贴板。

## 手动模式与手机录制

1. 进入 COCO 控制页，点击“手动模式”。
2. 两个滑动条均为 0–100 连续范围，整块横向轨道区域都可按下或拖动；最低值直接显示 `0`。
3. 点击圆形播放键开始发送；运行中平滑拖动任一滑动条，最新组合会按固定短间隔持续写入设备，松手时再次确认最终值。
4. 点击方形停止键结束并发送停止指令。
5. 要保存一段操作时，在停止状态点击“创建频率”。程序会同时开始播放和录制。
6. 调节参数后点击停止键或“完成并保存”，输入名称，频率会直接加入本机列表。

手机录制只保存成功发送的控制帧、相对时间和最终停止帧，不需要电脑、云端或重新上传体验版。当前手动编码集中在 `miniprogram/devices/coco/manual-protocol.js`；连续输入会归一化到已知有效控制码，拖动过程只保留最新组合，松手时会重复写入最终状态，以降低无响应写入丢失造成的滞后。数值到 0 时不再使用会产生最低档动作的推导数据，而是先发送已确认的全局停止数据；另一项仍大于 0 时，再重新发送该项的有效数据。

## 导入频率

1. 把 `.haohao-frequency.json` 文件发送到微信聊天或保存到手机文件中。
2. 进入“设备管理”，点击当前连接的 COCO。
3. 点击顶部“导入频率”。
4. 选择目标 JSON 文件。
5. 导入成功后，新条目会显示“本机”标签。

导入时会检查设备画像、帧时间、最终停止数据和完整性摘要。导入已有文件只需要手机，不需要重新上传小程序体验版。

## 管理本机频率

- 频率列表只保留播放操作；点击本机导入或手动录制的条目进入详情后，页面底部会显示与导出按钮同级的“修改名称”和“删除频率”按钮。按钮保持完整触控尺寸，但不占据页面主操作区。内置频率保持只读。
- 改名只更新列表名称，不改变控制帧、时长或完整性摘要。
- 删除需要再次确认，确认后会从微信本地存储移除。
- 频率运行或停止尚未完成时，管理操作暂时停用。

## 断开与重新连接

- 在 COCO 控制页点击“断开蓝牙”可立即结束当前功能并关闭连接。
- 主动断开后页面会返回设备管理，扫描保持停止。
- 回到设备管理点击“开始扫描”可重新寻找并连接。

## 获取新的频率

手动模式创建的频率可只用手机完成。已有频率文件也可以直接在手机导入。从原控制程序复制一段现成自动模式时，仍需先在 iPhone 采集诊断数据，再在电脑运行 COCO 专属工具：

```powershell
python tools\coco\extract-frequency.py INPUT --list
```
