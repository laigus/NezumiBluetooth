# 第一次微信小程序开发指引

本文只说明如何把本项目导入微信开发者工具、真机预览、上传和配置体验成员，不包含具体设备的操作方法。设备使用请进入对应模块文档，例如 [COCO 使用文档](coco/README.md)。

## 需要理解的几个入口

- **微信开发者工具**：在电脑上导入项目、编译、预览和上传。
- **微信公众平台**：管理 AppID、小程序名称、头像、成员和线上版本。
- **真机预览**：开发者工具生成二维码，手机微信扫码运行尚未上传的代码。
- **体验版**：把已上传的开发版本设为体验版，供已添加的体验成员使用。

## 注册并取得 AppID

微信官方注册链接：

<https://mp.weixin.qq.com/wxopen/waregister?action=step1>

注册完成后，在公众平台的“设置与开发 → 开发管理 → 开发设置”中复制 AppID。

## 安装微信开发者工具

官方下载页：

<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>

安装 Windows 稳定版，启动后使用微信扫码登录。

## 导入项目

首次克隆仓库后，在项目根目录复制公开示例配置：

```powershell
Copy-Item -LiteralPath project.config.example.json -Destination project.config.json
```

然后：

1. 打开本机 `project.config.json`，把示例 AppID 换成自己的 AppID。
2. 在开发者工具中点击“+”或“导入项目”。
3. 目录选择项目根目录 `NezumiBluetooth`，不要只选择 `miniprogram/`。
4. 项目名称可填写“耗耗蓝牙”。
5. 后端服务选择“不使用云服务”。
6. 点击“导入”。

`project.config.example.json` 可以提交，含真实 AppID 的 `project.config.json` 和开发者工具生成的 `project.private.config.json` 均由 `.gitignore` 排除。配置中已经声明 `miniprogram/` 为小程序源码目录；`docs/`、测试和本地工具不会作为小程序运行代码使用。

## 编译与真机预览

1. 修改源码后回到开发者工具点击“编译”。
2. 先在模拟器确认页面能正常打开。
3. 点击“预览”，用手机微信扫码。
4. BLE 扫描、连接、通知和写入必须以真机结果为准。

源码修改已经直接写入磁盘，不需要额外执行“保存项目”。上传前重新编译并完成一次与改动相关的真机检查即可。

## 本地校验

在项目根目录运行：

```powershell
pnpm test
```

该命令用于检查运行时代码引用、BLE 核心和已注册设备模块的稳定契约。它不会代替开发者工具编译或真机 BLE 验证。

## 上传并设置体验版

1. 在开发者工具中完成编译和真机预览。
2. 点击右上角“上传”，按界面要求填写上传说明并确认。
3. 打开微信公众平台，进入“管理 → 版本管理”。
4. 向下找到“开发版本”；新上传内容可能位于页面较下方。
5. 将目标开发版本设为体验版。
6. 体验成员退出旧页面，再从最近使用的小程序或体验入口重新进入。

## 添加体验成员

1. 在微信公众平台打开成员管理。
2. 添加对方的微信号，并赋予体验权限。
3. 确认已经设置体验版。
4. 把体验二维码或小程序入口发给该成员。

未加入体验成员列表的微信账号不能进入仅作为体验版发布的内容。

## 修改微信中的名称和头像

开发者工具中的导航栏标题只影响小程序内部页面。微信列表中的名称和头像在公众平台设置：

1. 进入“设置与开发 → 基本设置”。
2. 设置小程序名称。
3. 上传头像；本项目的品牌图位于 `assets/haohao-bluetooth-avatar.png`。
4. 保存后重新进入小程序检查展示结果。

## 常见判断

- **版本管理里看不到刚上传的内容**：先向下查看“开发版本”。
- **模拟器里蓝牙行为异常**：改用手机真机预览或体验版检查。
- **页面空白**：先查看开发者工具控制台错误，再运行 `pnpm test` 检查引用和运行时文件。
- **成员打不开体验版**：核对微信号、体验权限以及当前是否已经设置体验版。
